## `> ls /featured-projects`

<details open>
<summary><b>&#9654; TrustGraph-AI — Verifiable AI on Blockchain</b></summary>

A trustworthy AI execution platform: multi-agent pipeline (Planner → Retriever → Validator → Reasoner → Summary), paid per-call via x402 micropayments on a unified USDC balance, with every result Merkle-hashed and anchored on Arc, Circle's stablecoin-native L1.

| Aspect | Detail |
| :-- | :-- |
| **Stack** | Next.js · TypeScript · PostgreSQL · Merkle trees · Arc Blockchain · Circle Gateway · x402 |
| **What it solves** | Lets users cryptographically verify an AI agent's reasoning and payment trail, instead of just trusting the output |
| **My role** | Solo-built — architecture, multi-agent orchestration, smart contract integration, on-chain receipt system |
| **Repo** | [View](https://github.com/Chandru-007A/TrustGraph-AI) |

</details>
